Security

Keep API_ENCRYPTION_SECRET only on the external website backend/server.

The encrypted payload uses AES-256-GCM.

The normalized X-API-Domain header is authenticated as AES-GCM additional authenticated data (AAD).

The domain is therefore not part of the decrypted JSON payload, but it is cryptographically bound to it.

The server accepts only domains configured in API_DOMAIN_WHITELIST.

Every request also requires a fresh nonce and a valid timestamp.

No client-IP field and no application rate-limiting feature are used.
